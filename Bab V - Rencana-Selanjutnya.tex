\chapter{RENCANA SELANJUTNYA}
\label{chap:rencana-selanjutnya}

\section{Tahapan Penelitian}

Penelitian akan dilaksanakan melalui tahapan sistematis:

\begin{enumerate}
    \item Literature review dan requirement analysis.
    \item Infrastructure setup dan configuration untuk kedua platform.
    \item Load testing dan performance measurement.
    \item Power measurement dan Total Cost of Ownership analysis.
    \item Decision framework development.
    \item Documentation dan reporting.
\end{enumerate}

\section{Timeline}

\begin{itemize}
    \item Estimasi durasi penelitian: 5-6 bulan.
    \item Fase awal (1-2 bulan): literature review, requirement analysis, infrastructure setup.
    \item Fase eksperimen (2-3 bulan): testing, data collection, performance measurement.
    \item Fase akhir (1-2 bulan): analisis data, framework development, dokumentasi.
\end{itemize}

\subsection{Milestone Utama}
\begin{itemize}
    \item Proposal approval dan finalisasi requirements.
    \item Deployment functional pada kedua platform.
    \item Performance data collection selesai.
    \item TCO analysis dan framework development selesai.
    \item Thesis submission dan presentasi.
\end{itemize}

\section{Kebutuhan Sumber Daya}

\subsection{Hardware dan Software}
\begin{itemize}
    \item Hardware untuk testing (edge computing device, monitoring tools).
    \item Cloud subscription untuk periode eksperimen.
    \item Tools untuk load testing dan monitoring performa.
\end{itemize}

\subsection{Kompetensi}
\begin{itemize}
    \item System administration untuk deployment dan konfigurasi.
    \item Database management untuk setup dan optimasi.
    \item Data analysis untuk evaluasi performa dan biaya.
\end{itemize}

\subsection{Budget}
\begin{itemize}
    \item Procurement hardware untuk deployment lokal.
    \item Cloud subscription selama periode pengujian.
    \item Miscellaneous expenses (listrik, peralatan pendukung).
\end{itemize}

\section{Analisis Risiko}

\begin{itemize}
    \item \textbf{Hardware failure:} Mitigasi dengan backup hardware dan dokumentasi setup lengkap untuk recovery cepat.
    \item \textbf{Keterbatasan performa edge device:} Mitigasi dengan optimasi konfigurasi dan penyesuaian scope pengujian sesuai kapabilitas hardware.
    \item \textbf{Biaya cloud melebihi budget:} Mitigasi dengan monitoring usage ketat dan optimasi resource allocation.
    \item \textbf{Data loss selama eksperimen:} Mitigasi dengan backup rutin dan redundansi data pada storage terpisah.
    \item \textbf{Timeline delay:} Mitigasi dengan jadwal fleksibel dan prioritisasi task kritis untuk memastikan deliverables utama tercapai.
\end{itemize}

\section{Analisis Solusi}

\subsection{Aspek Evaluasi}
\begin{itemize}
    \item Performance adequacy untuk workload UMKM.
    \item Resource constraints dan limitasi teknis.
    \item TCO comparison antara edge computing dan cloud.
    \item Deployment complexity dan ease of maintenance.
\end{itemize}

\subsection{Trade-offs}
\begin{itemize}
    \item Identifikasi kelebihan dan kekurangan masing-masing alternatif infrastruktur.
    \item Analisis kondisi optimal untuk deployment edge computing vs cloud.
    \item Basis pengembangan decision framework untuk praktisi.
\end{itemize}

\section{Kriteria Keberhasilan}

\begin{itemize}
    \item Performance metrics dalam range acceptable untuk workload UMKM.
    \item TCO advantage signifikan untuk horizon multi-tahun pada deployment edge computing.
    \item Successful deployment dengan core business modules functional.
    \item Comprehensive cost model dengan actual measurements.
    \item Documented methodology yang reproducible.
    \item Decision framework yang actionable untuk praktisi.
\end{itemize}
