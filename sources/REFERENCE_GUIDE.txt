USAGE TIPS
================================================================================

1. When citing a topic, check this guide FIRST
2. Use the suggested source unless you have a specific reason to use another
3. If topic needs multiple citations: goldston + firdaus + maddodi
4. For UMKM/Indonesian context: Always prioritize Indonesian sources
   (firdaus2024, uuumkm2008, faturrahman2025)
5. For technical architecture: Newman (microservices) or Putra (clustering)
6. For TCO/costs: buijsse2024reference + aroca2012towards
7. For hardware decisions: blem2013power + aroca2012towards
8. Cross-reference: If citing Putra (Raspberry Pi), consider also aroca2012towards
   (ARM power efficiency)
