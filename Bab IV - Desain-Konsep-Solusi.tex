\section{Gambaran Umum Solusi}

Penelitian ini mengusulkan kerangka kerja evaluasi kelayakan teknis dan finansial sistem ERP pada infrastruktur alternatif berbasis \textit{Single-Board Computer} (SBC). Pendekatan evaluasi mencakup:

\begin{itemize}
    \item \textbf{Evaluasi Performa:} \textit{Benchmarking} performa aplikasi ERP pada platform SBC dibandingkan dengan platform \textit{cloud} VPS sebagai \textit{baseline}.
    \item \textbf{Analisis Ekonomi:} Perhitungan dan perbandingan \textit{Total Cost of Ownership} (TCO) untuk periode 3 dan 5 tahun antara investasi SBC (\textit{CAPEX}) dan biaya sewa VPS komersial (\textit{OPEX}).
    \item \textbf{Studi Kasus:} Orange Pi 5 Pro sebagai representasi platform SBC, dan Oracle Cloud Free Tier sebagai platform evaluasi performa, dengan VPS komersial (Hostinger/Biznet/DigitalOcean) untuk analisis TCO.
\end{itemize}

\section{Perbedaan dengan Sistem Saat Ini}

\subsection{Arsitektur Tradisional (\textit{Baseline})}

Saat ini, \textit{deployment} sistem ERP untuk skala kecil hingga menengah umumnya menggunakan salah satu dari dua pendekatan berikut:

\begin{itemize}
    \item \textbf{\textit{Cloud} VPS (Virtual Private Server):}
    \begin{itemize}
        \item Model investasi: OPEX (\textit{Operational Expenditure})
        \item Biaya berulang bulanan (Rp 100.000 - Rp 500.000/bulan untuk VPS komersial)
        \item Skalabilitas tinggi, namun biaya kumulatif tinggi untuk jangka panjang
        \item Ketergantungan pada penyedia layanan dan koneksi internet
    \end{itemize}

    \item \textbf{\textit{On-Premise} Server Tradisional:}
    \begin{itemize}
        \item Model investasi: CAPEX (\textit{Capital Expenditure}) tinggi
        \item Biaya awal signifikan (server \textit{entry-level}: Rp 10-30 juta)
        \item Konsumsi daya tinggi (50-200W), biaya listrik Rp 200.000 - Rp 800.000/bulan
        \item Memerlukan ruang fisik dan infrastruktur pendukung (pendingin, UPS)
    \end{itemize}
\end{itemize}

\subsection{Arsitektur yang Diusulkan (SBC-\textit{Based})}

Solusi yang diusulkan dalam penelitian ini mengeksplorasi alternatif ketiga:

\begin{itemize}
    \item \textbf{\textit{Single-Board Computer} (SBC):}
    \begin{itemize}
        \item Model investasi: CAPEX rendah (Orange Pi 5 Pro: ~Rp 2-3 juta)
        \item Konsumsi daya sangat rendah (5-15W), biaya listrik ~Rp 20.000 - Rp 60.000/bulan
        \item Kontrol penuh atas infrastruktur (\textit{on-premise}) tanpa biaya berulang tinggi
        \item Portabilitas tinggi, footprint fisik minimal
        \item \textit{Trade-off}: Keterbatasan performa dibandingkan server tradisional, namun berpotensi mencukupi untuk beban kerja ERP skala kecil-menengah
    \end{itemize}
\end{itemize}

\textbf{Komponen yang Identik (untuk Evaluasi \textit{Fair}):}
\begin{itemize}
    \item \textbf{Software Stack:} Linux OS (Ubuntu/Armbian), Nginx (web server), ERPNext (aplikasi ERP), MariaDB/PostgreSQL (database), Redis (caching)
    \item \textbf{Dataset:} Dataset demo identik untuk memastikan beban kerja yang sama
    \item \textbf{Konfigurasi:} Parameter database, setting ERPNext, dan optimasi OS disesuaikan agar setara
\end{itemize}

\textbf{Komponen yang Berbeda (Objek Evaluasi):}
\begin{itemize}
    \item \textbf{Hardware Platform:} Orange Pi 5 Pro (ARM) vs. Oracle Cloud Free Tier (x86/ARM cloud)
    \item \textbf{Lokasi:} On-premise (SBC) vs. Cloud (VPS)
    \item \textbf{Model Biaya:} CAPEX rendah + OPEX minimal (SBC) vs. OPEX berulang (VPS)
\end{itemize}

\textbf{Testing dan Monitoring:}
\begin{itemize}
    \item \textbf{Load Testing:} Aplikasi berbasis Go untuk simulasi beban kerja (API calls, concurrent users, transaction patterns)
    \item \textbf{Monitoring:} \textit{System metrics} (CPU, RAM, I/O disk) dan \textit{application metrics} (response time, throughput, error rate)
\end{itemize}
